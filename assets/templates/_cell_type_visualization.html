Molecular values

Each point represents a source observation. Values come from the selected modality's stored matrix, with its original feature identities and value type. No additional normalization or biological inference is performed.

Log1p changes only the color scale; hover values remain unchanged. Color ranges are calculated independently for the selected feature and sample, so equal colors across features or samples need not mean equal values.

Measured zeros remain valid measurements. Gray points indicate a missing modality or a non-finite stored value, with the reason shown on hover. Higher signals (larger absolute values for diverging colors) are drawn last to remain visible in overlapping regions; all observations are retained.

Genomic intervals, receptor sequences and taxonomic features retain their source meaning.
