当作完成承诺。最初一批部分小样本已报告 Seurat v3 HVG 的 `svddc`/近奇异数值错误，队列继续
执行。没有为绕过错误擅自改变特征选择规则；这些任务保留失败报告，单独后续处理。

正常停止可以对 supervisor 发送 SIGTERM；它会停止当前工作进程组并保存中断状态。恢复时
使用以下命令，不重新 prepare，不修改冻结文件：

```bash
run_root="$PWD/temp/spatial_domain_full_20260919T123330Z"
python_path="$PWD/temp/spatial_domain_runtime/iscdc-spatial-domain/bin/python"
PYTHONPATH="$run_root/code/src" nohup setsid "$python_path" -u -m iscdc.spatial_domain_batch run \
  --run-root "$run_root" --heartbeat-seconds 60 \
  </dev/null >>"$run_root/supervisor.log" 2>&1 &
```

先确认原 supervisor 已退出；运行目录锁也会阻止同时启动第二个 supervisor。恢复会接续
中断项，保留已记录失败项，已成功项不重算。新 PID 以 `progress.json` 为准。`complete` 仅表示
队列全部处理完毕，需结合成功、失败、跳过数量评估结果。
