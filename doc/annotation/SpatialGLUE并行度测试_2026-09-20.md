# SpatialGLUE 多规模资源与并行度测试（2026-09-20）

继 [首次接入验证](SpatialGLUE接入记录_2026-09-20.md) 后，按用户要求扩大规模覆盖并提高
任务并行度。所有输出位于 `temp/spatialglue_concurrency_20260920/`，源 H5MU 与正式
catalogue 只读；测试结果不发布到线上。

## 方法

选取 901、2,492、2,653、4,519、5,756、9,215、9,752 个观测的数据，以及仅 2,133 个观测
但包含 RNA、ATAC 和组蛋白两套大规模峰特征的样本。观察数与稀疏矩阵非零元素规模共同
影响资源占用，不能只按细胞数决定并行度。明确工作负载及原始矩阵字节数见 `workload.json`。

测试器为 `annotation/spatial_domain/gpu/benchmark.py`，仅用于明确列举的数据集和隔离
输出目录。使用已锁定 GPU 环境；保持正式预处理、图构建与聚类参数，短测仅覆盖 epochs
为 120，完整复核使用各模态组合默认轮数。短测生成的域标签不作为正式推断结果。
每类数据重复两次，任务顺序固定为按预估内存从大到小，再按资源余量选择可启动任务。
每任务固定 2 线程，通过不重叠 CPU affinity、全局空间域锁和 GPU UUID 锁管理。

每任务主存预算取预检估计的 1.15 倍向上取整后加 1 GiB，至少 3 GiB；显存预算取估计的
1.25 倍向上取整后加 1 GiB，至少 3 GiB。正在运行的任务预算之和受 128 GiB 主存、
64 GiB 显存上限以及启动时可用量减 8 GiB 限制。每秒监测任务 RSS、任务 CUDA 进程显存、
整卡状态与可用主存；单任务/总量超限或余量低于 8 GiB 时停止本次测试。
请求并行数是上限，报告同时记录资源约束下真正达到的并行数。

GPU 上已有其他计算进程，空闲时整卡利用率也约为 100%；因此报告将本次任务的进程显存
与整卡占用分开，吞吐量结论仅适用于测试时的共享负载。测试不停止或修改其他进程。

典型命令（在 `iscdc-spatial-domain-gpu` 环境运行）：

```bash
PYTHONPATH=src python -u annotation/spatial_domain/gpu/benchmark.py \
  --workload temp/spatialglue_concurrency_20260920/workload.json \
  --catalogue temp/spatialglue_concurrency_20260920/catalog.db \
  --output-root temp/spatialglue_concurrency_20260920/short_w4 \
  --workers 4 --threads 2 --repeats 2 --epochs 120
```

输出目录必须为新目录，不能覆盖已有测量。省略 `--epochs` 执行完整默认训练。
每次测试的 `profile.json` 记录任务耗时、并行数、峰值主存和任务显存，`telemetry.jsonl`
保存逐秒观测。每个任务另有 `timings.json`、实际配置、日志和完整 sidecar。


## 本轮结果与暂停点

按用户“完成这个之后暂时中止”的要求，完成正在运行的 **4 并发、每任务 2 线程、120 epochs**
短测后暂停。8 类数据各两次，共 16 个任务全部完成并通过各自的源校验和与 sidecar 完整性
检查。尚未测试 8 并发及更高档位，也未进行本轮候选配置的完整默认轮次复核。

全组耗时 **549.56 秒**，实际峰值并行数 4，工作进程 RSS 合计峰值 **20.26 GiB**，CUDA
工作进程显存合计峰值 **2.61 GiB**。进程显存包含 CUDA 上下文等开销，不等于 PyTorch allocator
统计；上述合计不包含监测主进程的固定开销或其他用户的 GPU 进程。单任务耗时中位数 61.87 秒、P95 为 320.99 秒。

### 重复运行检查

8 类数据的配对、预处理及模型输入图摘要均一致。联合表示最大绝对差在 1.19×10⁻⁷ 至
2.02×10⁻⁷，全部通过 `atol=1e-6, rtol=1e-5`；6 类数据域标签完全一致。另两类需进一步
验证：

- 9,215 观测 RNA＋ATAC：858 个域编号不同，域数为 12 / 11，ARI = **0.94149**。
- 9,752 观测 RNA＋H3K27me3：71 个域编号不同，两次均为 13 域，ARI = **0.98679**。

首个可观察的数值差异出现在联合表示，PCA 与聚类图摘要也随后不同。仅凭本轮测试，
不能认定差异由并行数或短训练轮数单独造成。恢复后须完成默认轮次及重复性复核；本次
不修改科学计算规则、不对标签做人工对齐、不发布短测结果。完整差异见 `replay-details.json`。
