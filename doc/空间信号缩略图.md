# 空间信号缩略图

## 用途与边界

为没有原生图片、没有注册 `he_wsi` 的 `full` 文件生成空间采样预览。
RNA 文件绘制观测点的 RNA 总计数；没有 RNA 时绘制空间点密度。页面明确区别两种信号，
并标注已知局部视野。图片只反映已经采集的观测及其信号，不能恢复未采集组织、证明
组织边界或代替 H&E。颜色仅在单张图内有相对意义。

首版覆盖需求基线为 231 个 Database 中缺图的 39 个文件：27 个 RNA 文件，
12 个无 RNA 文件（其中 11 个 S051 为独立局部视野）。仅支持单样本二维坐标。
遇到多样本、三维、非法值或未审核的阵列几何时明确失败，不自动拼图、投影或猜测比例。

## 固定渲染契约

方法为 `spatial-signal-v1`，manifest 版本为 1。参数变更需要更新方法版本。

1. 只读 catalogue v5 和正式 `dataset.h5mu`，计算实际 SHA-256 并与 catalogue 一致性核验。
   读取顶层 observation ID、sample、`obsm['spatial']`，RNA 按其 observation ID 匹配坐标；
   部分共享文件仅绘制 RNA 中存在的观测，审计记录顶层行号和实际绘图行数。
2. RNA 仅接受声明为 `counts` 的非负有限整数值 `X`。对 dense/CSR 分块逐行求和；
   CSC 按非零值块累加到行。不使用归一化 layer、不稠密化完整矩阵、不读取其他模态矩阵。
3. RNA 总计数取 `log1p`，第 1–99 百分位线性缩放到 `[0,1]`，使用固定 10 个 Viridis
   RGB 锚点线性插值。显示透明度为缩放值的平方，叠加在白底上；不做二值组织判定。
   百分位退化时，正信号使用固定中间色且不透明，零信号使用白底。
4. 无 RNA 时，在唯一空间位置上取第 16 个近邻距离 `r`，信号为 `16/(πr²)`；
   位置不足时取 `k=min(16,唯一位置数-1)`。重复位置共享同一个密度估计。
   密度同样经过 `log1p` 和第 1–99 百分位缩放，但圆点保持不透明。
5. 保留全部绘图坐标范围，四周留白为最大坐标跨度的 4%；x 向右、y 向下，等比例缩放。
   圆点半径为唯一位置最近邻距离中位数的 0.45 倍，转换到最终像素后限制在 0.75–6 px。
   采用四倍分辨率光栅化，重叠像素取缩放信号均值，然后使用 Lanczos 缩小。
   不作凸包填充、孔洞填充或跨空白区域插值。
6. 已审核的 S065 交错 Visium 索引仅在显示时将 y 乘以 `sqrt(3)`，核对整数和交错奇偶性。
   GSE213264 GBM 使用原始正方形网格；其他 `array_index` 不自动套用其中任一公式。
   S065 的换算依据为 [10x 的交错行列索引定义](https://www.10xgenomics.com/support/software/space-ranger/4.0/analysis/outputs/spatial-outputs)，
   来源身份和原始一基索引依据既有 S065 intake 审计。正式 H5MU 坐标保持原值。
7. 输出最大边长 640 px、RGB WebP、quality 85、method 6；源和显示坐标、信号、
   缩放后信号及 observation/feature IDs 保存在无 pickle 的 NPZ 审计中。

## 命令与存储

在 `iscdc` Conda 环境中执行：

```bash
PYTHONPATH=src python -m iscdc.cli generate-spatial-thumbnails DATASET_ID
PYTHONPATH=src python -m iscdc.cli generate-spatial-thumbnails --all
PYTHONPATH=src python -m iscdc.cli generate-spatial-thumbnails DATASET_ID --force
```

`--output-dir` 将 WebP 和 JSON 输出到预览或重放目录；默认输出到
`assets/static/database_thumbnails/spatial/`。文件名为 `<dataset_id>.webp` 和
`<dataset_id>.json`。`--audit-dir` 指定 NPZ 审计目录，默认是 catalogue 同级
`spatial_thumbnail_audits/`。审计文件使用 dataset ID 和数组内容摘要命名，保留历史结果。
运行时文件均忽略，不提交 Git；完整环境、代码快照和执行记录另存于对应 staging 审计。

单文件遇到已有输出时拒绝覆盖，`--force` 允许覆盖本方法的预览。批量默认跳过已有
预览、原生图片和已注册 WSI。任一文件失败返回 1；全部成功或全部跳过返回 0。
输出 JSON 分别记录 `generated`、`skipped`、`failures`，失败文件不回滚其他成功文件。

发布时锁定输出目录，在同目录暂存并验证图片及 JSON，依次原子替换图片和说明；说明是
提交标记，普通替换失败会恢复原文件。进程在两次替换间中止时，图片与说明校验和不符，
下次启动不展示该预览；修复后重启。拒绝符号链接输出文件和默认目录逃逸。

## 网站与验收

首轮实际发布结果见[2026-09-10 运行记录](空间信号缩略图运行记录_2026-09-10.md)。

启动时验证方法、参数、dataset/source/image 身份、信号类型、局部视野标识、观测数和
实际 RGB WebP 尺寸。缺失、损坏、过期图片 fail open，不影响页面和主下载。
原生图片优先；注册 `he_wsi` 后也停止使用空间预览，即使其 WSI 缩略图尚未生成。
网站不读 NPZ、不重新计算表达值、不修改 catalogue schema 或公开 JSON。

列表、entry 和文件详情共用带可访问替代文本的图片内容模板。详情显示与实际合成方式
一致的色阶、低信号淡化说明和跨图不可比较说明。已知局部视野显示 `Local field`。

发布前必须保存精确源哈希、代码（包括未提交内容）、固定环境、所有命令及实际参数，
从干净目录运行同一流程，比较有序 IDs、坐标、信号、解码 RGB 像素及 WebP 字节。
逐张检查联系表，覆盖组织内部空白、分离组织块、规则阵列和不规则细胞点云。
发布后重启应用，执行相关 ASGI 测试、实际页面及静态图片读取，以及桌面和手机浏览器
检查。保留截图、错误日志和原有图片／正式数据保护校验结果。不要求完整测试套件。
